# Como usar este template

Este modelo tem duas partes: o **README do perfil** (a página que aparece quando alguém abre o seu perfil no GitHub) e uma **versão em site** (pasta `docs/`), que é opcional.

## 1. Criar o seu repositório

1. Clique no botão verde **Use this template** e depois em **Create a new repository**.
2. Em **Repository name**, escreva **exatamente o seu usuário do GitHub**. Por exemplo, se o seu perfil é `github.com/maria-silva`, o repositório deve se chamar `maria-silva`.
3. Deixe como **Public** e clique em **Create repository**.

O GitHub só mostra o README no perfil quando o nome do repositório é igual ao do usuário e ele é público.

## 2. Editar o README.md

Abra o `README.md` e clique no lápis para editar. Troque:

| Procure por | Troque por |
| --- | --- |
| `SEU-USUARIO-GITHUB` | seu usuário do GitHub (aparece 4 vezes) |
| `SEU-LINKEDIN` | o final do endereço do seu LinkedIn |
| `SEU-INSTAGRAM` | seu usuário do Instagram |
| o bloco `const seuNome` | os seus dados |

As estrelas e os seguidores atualizam sozinhos. Para mudar as tecnologias, troque os endereços dos ícones. Você encontra outros em [devicon.dev](https://devicon.dev).

## 3. Trocar o banner

Coloque a sua imagem em `images/banner.jpg`. O tamanho ideal é parecido com **1790 x 670 pixels**.Eu deixei o meu banner se caso vc quiser usar e ele já está salvo como caminho no README.

## 4. Limpar o que você não vai usar

Depois de configurar, você pode apagar este arquivo (`COMO-USAR.md`), a pasta `docs/` e o `LICENSE`, se não quiser.

## 5. Versão em site (opcional)

A pasta `docs/` tem uma versão em HTML, com a fonte e as caixas arredondadas que o GitHub não mostra no README.

1. Copie a pasta `imagens` para dentro de `docs/`.
2. Edite `docs/index.html` (os links de LinkedIn e Instagram, e o bloco de código) e a primeira linha de `docs/script.js` (seu usuário do GitHub).
3. No repositório, vá em **Settings**, depois **Pages**. Em **Branch**, escolha `main` e a pasta `/docs`, e clique em **Save**.
4. Em alguns minutos o site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
